# RIFT: Last Signal — v1.0.0

The first playable release of RIFT: Last Signal, a standalone neon browser survival game.

Defend the Helios reactor for five minutes while reality shifts every 30 seconds. Fight rift creatures, collect repair shards, choose upgrades, and face three rift guardians.

## Included

- Ten sectors with changing gameplay rules.
- Six enemy types and eight upgrade modules.
- Phase dash and reactor pulse abilities.
- Procedural Canvas 2D visuals and synthesized sound.
- Desktop controls and a touch interface with automatic aiming and firing.
- Pause, restart, victory and defeat screens, and local high scores.
- Offline play without runtime dependencies.

## Getting started

Download and extract the release archive, then open `index.html` in a modern browser. See `README.md` for controls and gameplay tips.

## Known limitations

- The in-game interface is in Russian.
- High scores depend on browser storage availability and do not sync across devices.
- Mobile controls were checked in browser emulation; performance varies by device.

## Validation

32 game-mechanic checks passed alongside browser input and layout checks. No JavaScript errors were observed in the tested scenarios.
